# Task Manager React App

## Project Description

This is a simple Task Manager web application built using React. The goal of this project is to allow users to manage their tasks from one place.

The project is still unfinished and will be continued later. Currently, the website has a sidebar, an All Tasks page, a task input field, and a task table. Users can add a task name, and the new task will appear inside the table.

## Current Features

* Sidebar layout
* All Tasks page
* Task input field
* Add Task button
* Task table
* Ability to add a task title to the table
* Basic CSS styling

## How to Run the Project

1. Download or clone the project.

2. Open the project folder in VS Code.

3. Install the dependencies:

```bash
npm install
```

4. Start the project:

```bash
npm start
```

5. Open the website in the browser.

## Project Structure

The project currently contains React components for the main task page and the sidebar.

### Main Components

* `TaskMain`: displays the All Tasks page, task input, Add Task button, and task table.
* `Sidebar`: displays the sidebar navigation.
